# mirage

一个用 Go + SQLite 写的个人技术博客站。服务端渲染，前端零框架，部署时只有一个二进制文件。

定位很清楚：**给一个人用的私人小站**。只有站长和访客两级身份，没有注册、没有评论区、没有多用户。要的是「打开就能读、读完不折腾」。

## 站点最终长什么样

- **三套配色，每天自动换一套**：纸间（暖纸白 + 玫瑰灰）、青空（冷灰蓝 + 清蓝）、薄荷（微绿白 + 薄荷绿）。配色由服务端算好直接写进 `<html data-theme>`，首屏就对、不闪白，访客禁用 JS 看到的也是对的配色。
- **明暗两档**：访客自己切，记在 localStorage 里，翻页不丢。
- **目录可折叠**：桌面端右侧 sticky 栏，收起来正文重新居中；移动端是标题下方的折叠块。
- **板块是数据不是代码**：先做「手记」「关于」「留言」，以后想加「养鸟」「拍照」，后台插一行记录就行，导航和首页卡片自动跟上。
- **站长登录后**顶栏多出工具条：改内容、生成分享链接、切配色。访客的 HTML 里连这些按钮都不存在。
- **分享链接**：把一篇私密文章分享给指定的人，可设密码、有效期、访问次数；凭证只对单个链接有效。
- **改完即时生效**：没有构建环节，后台保存，前台刷新就是新的。

## 技术选型

| 项 | 选择 | 理由 |
|---|---|---|
| 语言 | Go 1.26 | 单二进制、内存占用低、部署只是传一个文件 |
| HTTP | 标准库 `net/http` + Go 1.22+ 的 `ServeMux` 方法路由 | 不引框架——路由、中间件本身就是要学的东西 |
| 模板 | 标准库 `html/template` | 同上；自动转义把 XSS 挡住一大半 |
| 数据库 | SQLite（`modernc.org/sqlite`，纯 Go 不需要 gcc） | 一个人的博客用不上服务端数据库；WAL + 读写双连接池（读 4 / 写 1） |
| Markdown | `goldmark` 渲染 → `bluemonday` 消毒 | 自己写的内容也当不可信输入处理 |
| 前端 | 手写 CSS + 一点点原生 JS | 没有构建步骤，改一行刷新就看见 |
| 字体 | 正文用系统字体（Times New Roman + 仿宋），不打包 | 少一个首屏请求 |

不引的东西列出来更清楚：没有 Web 框架、没有 ORM、没有模板引擎、没有前端框架、没有 CDN、没有代码高亮库。

目标数字：首屏 gzip 后 < 20 KB、外部请求 0 个、常驻内存 < 40 MB。

## 目录结构

```
mirage/
├── cmd/mirage-server/     入口：读配置 → 开库跑迁移 → 起 listener → 等信号
├── internal/
│   ├── config/            配置加载（flag > 环境变量 > 默认值）
│   ├── model/             领域模型（纯结构体）
│   ├── store/             数据访问层：开库、迁移器、查询方法
│   └── web/               HTTP 层：路由、中间件、handler
├── migrations/            NNN_xxx.sql 迁移文件 + embed 指令
└── docs/                  设计文档与学习笔记
```

`templates/`、`static/` 会随 M3、M9 落地。

## 快速开始

```bash
git clone <repo> mirage
cd mirage

cp .env.example .env        # 填 MIRAGE_SECRET：openssl rand -hex 32
go run ./cmd/mirage-server -dev

curl http://127.0.0.1:8091/healthz   # {"status":"ok"}
```

配置三级优先：命令行 flag > 环境变量 > 代码默认值。密钥只从环境变量读、不给 flag——命令行参数在 `ps` 里是明文。

数据库在启动时自动建表并补跑迁移；迁移失败就拒绝启动，不带着半截 schema 继续跑。

## 关于这个项目

这是个练手项目：代码要读得懂、能学到东西，不是「跑起来就行」。所以每个里程碑结束都会写一节学习笔记，写完才算这阶段真学到了。

部署形态很朴素：单二进制跑在一台内存 1.9 GB 的 Ubuntu VPS 上，静态资源和反向代理由 Nginx 负责，服务本身只写 stdout 日志。
